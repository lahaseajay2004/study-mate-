# 📚 StudyMate

StudyMate is a smart learning workspace developed as a college project.
It combines note-taking, AI assistance, and productivity tools into a single platform.

## 🎓 Project Info

* **Type:** College Project
* **Domain:** AI & Data Science
* **Purpose:** Improve learning efficiency using AI-powered tools

## 🚀 Features

* 📝 Block-based note editor
* 🤖 AI-powered note explanation, summarization, and rewriting
* 🧠 Context-aware AI chat per subject and note
* 🖼️ Image and video integration
* 📌 Task blocks and productivity tools
* 🎨 Clean UI with dynamic background

---

## 🧠 AI Capabilities

* Explain selected text
* Summarize notes
* Rewrite content clearly
* Elaborate concepts
* Context-based chat memory

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express
* **Database:** JSON-based storage (custom)
* **AI Integration:** Custom AI service


## ⚙️ Installation & Setup

create .env file with
* OPENROUTER_API_KEY = (From OpenRouter)
* OPENROUTER_MODEL = (From OpenRouter / Any model With Img Support)
* UNSPLASH_KEY = (From Unsplash)
* YOUTUBE_API_KEY = (From Google Cloud Console)
* CLIENT_ID = (From Google Cloud Console)
* CLIENT_SECRET = (From Google Cloud Console)
* REDIRECT_URI = http://localhost:3000/profile/google/callback
```bash
git clone https://github.com/your-username/studymate.git
cd studymate
npm install
npm start
```

Then open:

```
http://localhost:3000
```
